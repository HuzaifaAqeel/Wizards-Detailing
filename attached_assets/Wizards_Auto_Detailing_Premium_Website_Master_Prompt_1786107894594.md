# Master Website Generation Prompt — Wizard’s Auto Detailing

## Project Goal

Design and build a **premium, elite, high-converting automotive detailing website** for **Wizard’s Auto Detailing / Wizards Mobile Detailing**, a professional mobile auto detailing business serving **Montreal and surrounding areas**.

The existing brand identity shown on Instagram is based on **black, metallic gold, and white**. The website must expand that identity into a polished luxury experience that feels comparable to a premium automotive brand, high-end ceramic coating studio, or exotic car detailing company.

This must **not** look like a generic local-business template. It should feel custom-made, visually cinematic, technically polished, modern, fast, and expensive.

The website should immediately communicate:

- Premium automotive care
- Mobile detailing convenience
- Professional workmanship
- Trust and credibility
- Ceramic coating expertise
- Interior and exterior detailing
- Paint polishing / correction
- Easy online appointment booking
- Montreal-area service coverage

Use the Instagram profile **@wizards.detailing** as the brand/content reference.

Current visible Instagram information includes:

- Brand: **Wizards Mobile Detailing / Wizard’s Auto Detailing**
- Location/service area: **Montreal & surrounding areas**
- Core services: **Interior detailing, exterior detailing, polishing, ceramic coating**
- Mobile/work-site detailing is part of the business model
- Phone shown in existing branding: **438-872-0884**
- Primary visual identity: **Black + Gold + White**
- Existing visual tone: real customer vehicles, before/after work, mobile detailing setups, ceramic coating, polishing, interior cleaning, SUVs and sedans

Do **not invent a business email address, physical address, package price, warranty, opening hours, review count, certifications, or claims** unless these are later supplied. Use clearly editable placeholders where information is unavailable.

# 36. Scroll Reveal System

Use consistent reveal choreography.

Examples:

### Headings
Masked line reveal from bottom.

### Paragraphs
Opacity 0 → 1 with 20–30px vertical motion.

### Images
Clip-path reveal from bottom or left.

### Cards
Stagger 60–100ms.

### Dividers
ScaleX 0 → 1.

Use approximately:

- Duration: 0.6–1.0s
- Ease: `power3.out`, `power4.out`, or refined custom bezier

No bouncing.
